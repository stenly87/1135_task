# Desktop‑клиент (для сотрудников предприятий)
Данный модуль должен быть реализован в виде настольного приложения (не гибрид, не использовать WebView). 
При разработке модуля вы должны следовать предложенному дизайну приложения
Разрешённые платформы: C#/Avalonia, Java/Swing/JavaFX, Python/PyQt/Tkinter, Electron (только native UI элементы).

Общие технические требования к программе:
- Авторизация — через API /auth/login с JWT. Хранить токен в зашифрованном виде.
- Все операции — только через REST API, прямой доступ к БД запрещён.
- Адаптивность — корректное отображение на экранах 1366x768 и выше.

# Экран 1: Авторизация
Экран "Авторизация" предназначен для обеспечения безопасного доступа сотрудников предприятий к системе через JWT токен.
На данном экране реализуйте функции:
-	Ввод учетных данных — поля Email (TextBox 300px) и Пароль (PasswordBox с кнопкой "показать/скрыть"). Валидация: email формат, пароль >6 символов.
-	Авторизация через API — кнопка "ВОЙТИ" отправляет POST /auth/login с хешированным паролем, получает JWT токен.
-	Сохранение сессии — checkbox "Запомнить меня" сохраняет токен в защищённом хранилище.
-	Обработка ошибок — сообщения "Неверный email или пароль", "Сервер недоступен" при HTTP 401/500.

# Экран 2: Главная страница
Экран "Главная страница" предназначен для отображения ключевых метрик системы и быстрой навигации по модулям.
На данном экране реализуйте функции:
-	Отображение профиля пользователя — фото 40x40px, ФИО, роль в заголовке. Dropdown: "Мой профиль", "Настройки", "Выход".
-	Сводка по активности — 4 карточки 200x120px: "Активных профилей: 1 247 (+24)", "Соответствие вакансиям: 68% (-2%)", "Средний рейтинг: 7.2/10 (+0.3)".
-	Топ-5 технологий — горизонтальная таблица: "Python ███ 45% | JS ██ 32% | Java █ 18%".
-	Автообновление — кнопка "Обновить" и таймер каждые 5 минут (GET /dashboard/summary, /skills/top).
При входе отображается заголовок с фото пользователя 40x40px, ФИО, ролью и выпадающим списком с пунктами "Мой профиль", "Настройки", "Выход".
Блок сводки по активности содержит четыре карточки с метриками: количество активных профилей с суточным приростом, процент соответствия вакансиям с изменением, средний рейтинг с динамикой. Данные загружаются через GET /dashboard/summary.
Блок топ-5 технологий показывает горизонтальную таблицу с названием технологии, прогресс-баром заполнения и процентом. Данные обновляются через GET /skills/top.
Кнопка "Обновить" принудительно загружает свежие данные, автоматическое обновление происходит каждые 5 минут. При отсутствии данных показываются сообщение. Боковая панель навигации сворачивается в иконку меню на узких экранах.

# Экран 3: Поиск профилей
Экран "Поиск профилей" предназначен для поиска кандидатов по критериям с фильтрацией и сортировкой.

На данном экране реализуйте функции:

-	Выполнение поиска — кнопка "Найти" отправляет GET 
-	Таблица результатов — колонки: №, Кандидат (ID), Навыки, Рейтинг (с трендом 📈➡️📉), пагинация 25/50/100.
-	Быстрые действия — кнопка "Подробно" открывает карточку профиля в модальном окне.
При открытии экрана отображается панель фильтров с чипами технологий, автокомплитом при вводе (GET /skills/suggest) и выпадающими списками для диапазонов уровня навыков, опыта работы и рейтинга. Чипы технологий добавляются кнопкой "+" и удаляются крестиком.

Таблица результатов поддерживает пагинацию с переключателем 25/50/100 записей и сортировку по клику на заголовки колонок. Кнопка "Подробно" открывает карточку профиля кандидата в модальном окне. Кнопка "📤CSV" экспортирует текущие результаты.

# Экран 4: Карточка профиля
Экран "Карточка профиля" предназначен для детального просмотра анонимизированного профиля кандидата в режиме работодателя.

На данном экране реализуйте функции:
-	Основная информация — публичный ID (SKR-12345), ФИО скрыто, карточка рейтинга (индекс 85%, доверие 92%, 15 подтверждений).
-	Подтверждённые навыки — таблица: технология, уровень/10, количество подтверждений (✓✓✓).
-	Опыт работы — список с типом занятости (ТК РФ, фриланс), без контактов компании.
-	Действия — кнопки "← Назад", " ➕В подборку", "📄PDF-отчёт", "✉Пригласить" (заглушка).


При открытии экрана отображается заголовок с публичным ID кандидата в формате #ITP-12345 рядом с аватаром кандидата. ФИО показывается полностью только для публичных профилей, в режиме работодателя отображается "Фамилия И.И. (анонимный профиль)". Рядом с аватаром цветная точка показывает статус активности кандидата.
Карточка рейтинга надёжности содержит два горизонтальных прогресс-бара: индекс компетенций и доверие сообщества с процентным значением и цветовой индикацией. Под прогресс-барами статистика "Подтверждений: 15 | Навыков: 8". Данные загружаются параллельно с основным профилем с анимацией заполнения баров.
Таблица подтвержденных навыков содержит три колонки: технология, уровень в формате 9/10 и количество подтверждений в виде ✓✓✓ (3). Навыки сортируются по убыванию уровня, навыки без подтверждений отображаются серым текстом. При наведении на навык показывается всплывающая подсказка с датами подтверждений.
Список опыта работы содержит строки в формате "2023–2026 ООО Ромашка (ТК РФ) [Middle Python]" где тип занятости показывается иконкой. Текущая работа выделяется жирным шрифтом. Контакты компании и точный адрес скрыты.
Нижняя панель действий содержит четыре кнопки: "← Назад" возвращает на экран поиска с сохранением фильтров, "➕В подборку" открывает модальное окно множественного выбора подборок, "📄PDF" генерирует PDF текущего экрана с автоскачиванием, "✉Пригласить" показывает заглушку "Функция в разработке".

# Экран 6: Генератор отчётов
Экран "Генератор отчётов" предназначен для создания документов для руководства и архива.

На данном экране реализуйте функции:
-	Выбор параметров — тип отчёта (кандидат/подборка), ID, период (месяц/квартал).
-	Генерация отчёта — кнопка "Сформировать отчёт" запрашивает данные через API.
-	Предпросмотр — таблица или график результата в реальном времени.
-	Экспорт — кнопки "PDF", "Excel" с использованием библиотек.
При открытии экрана отображается панель параметров с выбором типа отчёта (кандидат или подборка), полем ввода ID с автокомплитом и выпадающим списком периода (месяц, квартал, год).
Кнопка "Сформировать отчёт" отправляет запрос на сервер и показывает блок предпросмотра в виде таблицы или графика с метриками навыков, рейтингов или соответствия вакансиям в зависимости от типа отчёта.
Блок предпросмотра обновляется в реальном времени при изменении параметров с индикатором загрузки. Кнопки "PDF" и "Excel" генерируют файл для скачивания с форматированием данных из предпросмотра. При ошибке генерации показывается сообщение с возможностью повторить.

# Экран 7: Аналитика рынка
Экран "Аналитика рынка" предназначен для визуализации трендов и принятия решений по подбору.
На данном экране при открытии реализуйте отображение:
-	Круговая диаграмма — распределение специалистов по технологиям (Python 45%, JavaScript 32%, Java 18%, другое 5%).
-	Линейный график — динамика среднего рейтинга за 30 дней с отметками тренда.
-	Таблица топ-10 технологий — sortable: название, средний уровень, количество специалистов.
-	Фильтры — выбор периода (30/90 дней), экспорт данных.
При открытии экрана отображается круговая диаграмма распределения специалистов по технологиям с подписями процентов (Python 45%, JavaScript 32%, Java 18%, другое 5%) и выпадающий список фильтров периода (30/90 дней).
Линейный график показывает динамику среднего рейтинга за выбранный период с отметками тренда и подписью текущего значения. Таблица топ-10 технологий содержит колонки название, средний уровень и количество специалистов с возможностью сортировки по клику на заголовки.
Кнопка "📤Экспорт" генерирует CSV файл с данными таблиц и графиков. При смене периода диаграммы и график обновляются с индикатором загрузки. При отсутствии данных показывается сообщение "Недостаточно данных для анализа". Фильтры сохраняются в URL.
